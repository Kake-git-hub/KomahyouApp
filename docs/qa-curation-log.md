# QA 整理の記録（質問・要望 → 説明書の QA へ）

「質問・要望」で届いた報告のうち、整理が終わった受付番号を記録する。`tools/question-qa-digest.mjs` はこの表の 1 列目を読み、
載っている受付番号を次回の QA 候補パックから外す。手順は `docs/runbooks/question-qa-loop.md`。

- **1 列目は受付番号そのまま**（`20261015-151056959-a8890098` の形。バッククォートは任意）。それ以外の列は人が読むためのメモ。
- 結果の語: `QA 追加`（説明書 11 章へ足した）／`本文修正`（説明書の章を直した）／`要望 Issue`（Issue を起票・番号を反映先に）／
  `保留`（オーナー判断待ち。理由をメモ）／`対象外`（テスト・重複・個別対応で完了・QA にしない）。
- 利用者の本文や生徒名はここに書かない（受付番号で引ける）。
