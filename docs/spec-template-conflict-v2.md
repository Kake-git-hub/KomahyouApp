## 0. 目的と置き換える範囲

- **目的**: テンプレを反映したときの盤面を、**「出自の印」と 4 本の規則**だけで決める。場合分けを積み上げない。
- **置き換える**: §H の Q21〜Q42（何を捨てるかは §6）。
- **変えない**: Q1（反映日より前は触らない）・反映日の既定・保存前の自動バックアップとレポート PDF（Q32-2・-3）・
  保留データの置き場（Q24）・2 行の机では出席を付けない（Q27）・1 行に戻る条件（Q28）・フラグ（Q33）。
- **反映の範囲**: 反映日以降の、盤面に生成済みの週の**全コマ**。毎回すべて当て直す（§6 Q39）。

## 1. 用語

| 用語 | 意味 |
|---|---|
| 出自の印 | 盤面のデータを**置いた瞬間**に記録する 2 値。`テンプレ`／`手入力`。種別（通常・振替など）から推測しない。 |
| テンプレ由来 | 印が `テンプレ`。テンプレの展開で置かれたもの。反映のたびに新テンプレで置き直す。 |
| 手入力データ | 印が `手入力`。人の操作で置いたもの（QR 提出で自動で入った講師も含む・§9-13）。反映で**消さない・動かさない**。 |
| 席 | 机 × 席（生徒 1／生徒 2）。2 行（緑）にする単位。 |
| 2 行 | 1 つの席（または机の講師欄）に、上＝テンプレ・下＝手入力が並ぶ状態。 |
| 休みの記録 | 生徒＝出欠記録（休み・振無休・出席・別日移動の「移)」）。講師＝新設の「休み」（§2-4）。 |

## 2. 反映の規則

当てる順番は **丸ごと振替（§3）→ 休み → 生徒の一意 → 講師の一意 → 席**。前の規則で置かないと決まったものは、後の規則で置かない。

### 2-1. 席の規則（基本）

| 反映先の席の今 | 新テンプレがその席に置くもの | 結果 |
|---|---|---|
| 空 または テンプレ由来 | 生徒 | テンプレの生徒（1 行） |
| 空 または テンプレ由来 | なし | 空（テンプレ由来は外れる） |
| 手入力の生徒・メモ | 生徒 | **2 行**（上＝テンプレ／下＝手入力） |
| 手入力の生徒・メモ | なし | 手入力のまま 1 行 |
| 休みの記録だけ（別の生徒） | 生徒 | テンプレの生徒を置く。記録は残す（§9-10） |

- 机の突き合わせは**同じコマの机番号どうし**。コマ表の「並び替え」は表示中の週だけ、テンプレ由来の机も手入力の机も動かす（§9-22 案 A・2026-11-06 オーナー選択）。固定するのは保留（2 行）の机だけ（旧 Q31）。読み込み直し（再マージ）では並び替えた形が残る（再マージは授業 ID で突き合わせ、講師の規則 §2-3・§9-15 も授業 ID の対応で「自分の机」を引く・`resolveBoardDeskIndexForManagedDesk`）。**次にテンプレを保存する直前**に、保存前のテンプレの机を基準に、テンプレ由来の机を授業 ID（無ければ同じ生徒・同じ講師）で元の机番号へ戻し、手入力だけの机は新しいテンプレが使わない机番号へ寄せる（無ければ今の番号に残り、§2-1 で 2 行）。そのうえで机番号で突き合わせる（`templateDeskOrderRestore.ts`・`runTemplateDiffApplyV2`）。並び替えていない週は参照ごと不変（INV-10）。
  - **手入力は講師について行く（2026-11-10 オーナー決定・緑が丘の報告・INV-02）**: 新しいテンプレで講師の机番号が変わっても、手入力の生徒・メモ・出欠記録が元の机番号に取り残されないよう、
    保存の直前に、盤面の机を**新しいテンプレの講師の位置**へ移してから机番号で突き合わせる（並び替えの戻しをこの規則に置き換える）。
    - 机の「講師」は、その机のテンプレの講師（足場講師。手で講師を替えた机・一時的に入れ替えた机は、机のテンプレの授業〔授業 ID〕が保存前のテンプレで乗っていた机の講師）。
      その講師が新しいテンプレの同じコマにいれば、机ごと（中身はそのまま）その机番号へ移す。テンプレ由来の生徒は新しいテンプレの位置に置き直されるので、結果として手入力だけが講師について行く。
    - その講師が新しいテンプレの同じコマに**いない**（別の講師に替わった・外れた）机に手入力（生徒・メモ・出欠記録・手置き講師）があれば、**テンプレが使う最後の机より下**の空き机のうち一番若いものへ移す
      （下に空きが無ければ、テンプレが使わない机のうち一番若いもの）。テンプレの講師は付けない（講師なしの机になる）。手置きの講師（青字）は机と一緒に移る。
      どちらにも空きが無いときだけ、残った机へ入る（別の講師の机に入りうるので、確認画面に「空いた机が無いので机 N（講師 X の机）に入ります」と出す）。
      保存前の確認画面に「講師が替わったので机 N へ移した生徒」を名前つきで出す。手入力の無い机はテンプレどおりに置き直されるだけ。
    - 講師の削除記録・講師の休み（§2-4）の机も、消した講師・休んだ講師について行く（取り残すと、削除した講師がテンプレで生き返るため・2026-11-10 主セッション判断）。
    - 講師名を固定しただけの机（生徒を動かして空いた机などの `manualTeacher` の印だけで、手で講師を置いた記録〔`teacherAssignmentSource`〕が無く、机のテンプレの授業の手がかりも無いもの）は、
      その講師が新しいテンプレの同じコマにいれば、その講師の机へついて行く（同じ講師なのでぶつからない）。
      手で講師を置いた机（手置き・入れ替え・QR）は対象外で、§9-15 の「手入力が勝つ」（決定記録 66・確認リスト tp-59 / v2-3）をそのまま守る。授業の手がかりがある机は授業の講師について行く。
    - 下段の講師を採用した記録（`templateTeacherDeclined`）は、採用した講師が今の机の講師のときだけ手がかりに使う。
    - 手で置いた講師（一時的な入れ替えを含む）は消さず動かさず、机と一緒に移る。移った先でテンプレが別の講師を置けば講師欄だけ 2 行（§2-3）。下段を採用済みの机（`templateTeacherDeclined`）は 1 行のまま。
      手置きの講師が新しいテンプレでは別の机にいるときは手入力が勝つ（§2-3・§9-15）。
    - 講師の手がかりの無い机（テンプレの授業だが講師なし等）は従来どおり授業 ID で保存前のテンプレの机番号へ戻す。手入力だけの机（講師なし・手置き講師）は従来どおり（今の番号がテンプレで使われていなければそのまま、使われていれば一番若い空き番号）。
    - 保留（2 行）の机・反映日より前・休日・丸ごと振替の日は動かさない。新しいテンプレの並びどおりに既に並んでいるコマは参照ごと不変（INV-10）。1 コマに同じ講師は 1 机（INV-01）。
    - 室長の「並べ替え」は保存のたびに新しいテンプレの並びへ戻る（§9-22 案 A のとおり。手入力だけの机はテンプレの机の下に付く）。
  - 基準の「保存前のテンプレ」は、**その日付に効いていた版**（保存前の履歴＋テンプレ前の行を `buildCombinedRegularLessonsFromHistory` で合成し、その日に有効な行だけ）。保存済みの最新版の行だけで作ると、最新版の反映日がその日より後（例: 2 月版を保存済みで 11 月の日へ反映）のとき基準が空になり、手入力の生徒が講師の机から散った（2026-11-10 緑が丘の報告・INV-02・`resolveTemplateDiffPreviousRows`）。丸ごと振替の時限の追従（Q40-9）も同じく、振替元の日に効いていた行で比べる。
- テンプレ机が講師だけ（生徒なし）なら、席の手入力生徒はそのまま残る（2 行にならない・決定 6）。

### 2-2. 生徒の一意（1 本規則）

- 同じコマ（日付×時限）に、**手入力の生徒 S** と**テンプレの同じ生徒 S** がぶつかったら、**手入力が勝つ**。テンプレの S はそのコマのどの机にも置かない。
- 前のテンプレ由来の S は「テンプレ由来」なので、新テンプレの S に置き直されるだけ（ぶつからない）。
- 「勝つ」根拠になる手入力の S は**上の行（机）に生きているもの**。手入力の S が**緑の下の行にしか居ない**ときは、下の行の S をテンプレが S を置こうとした席へ**自動で上げて 1 行**にする（§9-14・下の行は盤面だけの表示なので、日程表と回数から消さない）。上げる席が無ければ置かずに理由を出す。
- 置かなかったテンプレの S は予定数に数えない（§4 会計規則 1 と同じ扱い）。保存前の確認画面に「手入力が先にあるため置かない」と出す。
- これで INV-12（同じ生徒は同じコマに 1 か所）が構造で成り立つ。

### 2-3. 講師の一意（1 本規則）

| 机の講師の今 | 新テンプレの講師 | 結果 |
|---|---|---|
| 空・テンプレ由来 | X | X（テンプレに揃える） |
| 手置き講師 Y | X（Y と別人） | **講師欄だけ 2 行**（上＝X／下＝Y）。席は §2-1 で別に決める。 |
| 手置き講師 Y | なし | Y のまま |
| 講師の削除記録（X） | X | 置かない（空のまま） |
| 講師 X の休み | X | 置かない（§2-4） |

- **同じ講師は 1 コマに 1 机**（INV-01）。手置き講師 X の机 A があるのに、テンプレが別の机 B に X を置くときは、
  **手入力が勝つ**＝机 B に X を置かない（B のテンプレ生徒は置く・講師欄は空）。確認画面に理由を出す（§9-1）。
- 机 A（手置き X）にテンプレが別の講師 W を置き、さらに別の机 B に X を置く形では、**机 A の講師は X のまま**（W は置かず講師欄は 1 行・B にも X を置かない）。理由を確認画面に出す（§9-15）。
- QR 提出で自動で入った講師も手置き講師と同じ（手入力・青字・§9-13）。旧 Q21-9 例外 1（QR の講師を外す）は廃止。

### 2-4. 休みの規則（休みが勝つ）

| 対象 | 休みの記録 | テンプレが置こうとするもの | 結果 |
|---|---|---|---|
| 生徒 S | S の休み・振無休・出席・「移)」がそのコマにある | S | 置かない（記録が勝つ・実績は記録に残る）。記録は**そのコマだけ**に効く（同じ日の別の時限に S を置くことは止めない・§9-16） |
| 講師 X | X の休みがそのコマにある | X（どの机でも） | 置かない。机はグレーの「休」 |
| 講師 X | 同上 | その机の生徒 | 置く（机はグレー・講師なし・別の講師で上書き可）（§9-7） |

- 講師の休みは**盤面の新しい「休み」ボタン**で付ける（講師欄のメニュー・**1 コマごと**・「この日全部」の一括ボタンは作らない・§9-4）。別の講師を手で置いて上書きできる（休みの記録は残り、テンプレの X は引き続き置かない）。
- 解除は同じボタンをもう一度押す。休んだ講師本人をその机に手で置き直したときも自動で解除する（§9-19）。記録は盤面の週と同じ期間残る。操作ログには残さない（§9-8）。
- 見せる場所は**コマ表の画面だけ**。講師日程表・コマ表 PDF・保護者 QR には出さない（そのコマは講師なしの机として出る）（§9-8）。
- コマ表で講師を消した記録（§1-1 #14）は休みとは別のまま残す（§9-8）。
- 置き場の一案（実装側の判断）: 生徒の出欠記録（`statusSlots`）とは分け、机に任意項目 `teacherRest: { teacherId, origin: 'manual' }` を持つ。
  判定は「日付×時限×講師 ID」で引く（席を消費しない・講師の一意判定と同じ鍵）。

## 3. 丸ごと振替（日付の付け替え）

| 項目 | 規則 |
|---|---|
| 曜日 | **同じ曜日だけ**。別の曜日は選べない。 |
| 記録 | 「移動元の日 D → 移動先の日 D'」の**組 1 本**を教室データに残す。個々の振替を正本にしない。 |
| テンプレ反映 | D と D' の組は変わらない（D を休日設定にしていても）。**D の新テンプレの授業は D' の同じ時限・同じ机番号へ自動で展開**する。 |
| 見せ方 | D は「休)」、D' は「振)」（今と同じ）。D' の授業の出自は `テンプレ（付け替え）`＝青字にしない。 |
| D' のテンプレ | D' 自身のテンプレの授業は展開しない（**消去・在庫に入れない**。今の丸ごと振替の振替先の処分と同じ・§9-2）。組がある間、D' には D のテンプレだけが出る。 |
| D' の手入力 | D' に先に置いた手入力は §2-1 のとおり 2 行。 |
| 一部が来られない | D' でその生徒を「休み」にする → 振替在庫へ（通常の休みと同じ会計・振替元は D）。D のその席は、ほかの生徒と同じ「休)→D'」のまま（出席・振無休でも同じ。テンプレ由来の授業で D の席が空になっていたのを 2026-11-08 テスト教室 se-7 のメモで直した・v1.5.708）。D' で削除・格納した生徒は D に出さない（§4-1-2「消したまま」）。D' の中で別の机へ動かした授業（動かしただけ・そのあと休みにした）も、テンプレ由来・作成で D から移した手入力とも D に「休)→D'」が残り、未消化振替の振替元は D（2026-11-08 オーナー決定「元の日に揃える」・v1.5.709。それまではテンプレ由来だけ D が空だった）。未消化振替の表示が元の日 D（例「12/23 の振替」）であることは 2026-11-08 オーナー確認「元の日の表示でよい」。D' の別の時限へ動かしたら、D の「休)」の行き先（生徒日程表の振替先）は**動かした先の時限**を指す（2026-11-08 オーナー決定・v1.5.710。それまでは D の時限のままだった。保護者 QR は行き先を読まないので影響なし）。 |
| 在庫 | 付け替えそのものは在庫中立（`spec-makeup-stock.md` §B-2-3 と同じ）。 |
| 月をまたぐ | 予定数は移動元 D の月で数える（§9-3）。 |
| 解除 | 組を消すと D へ戻る。作成で D から D' へ移した手入力も D へ戻す（§9-20）。D' に記録（出席・休み）があるときは解除を止める。 |
| D' に同じ生徒の手入力 | D の S の授業は D' に置かず（§2-2）、D の S は「休み」として未消化振替へ（振替先は出さない・§9-21）。 |

## 4. 解決操作と会計

### 4-1. 解決操作（今のメニューをそのまま使う）

| 場所 | 操作 |
|---|---|
| 2 行の席 | 上段（テンプレ）を採用する／下段（手入力）を採用する／下段（手入力）を移動する／下段（手入力）を削除する |
| 2 行の講師欄 | 上段（テンプレ）の講師を採用する／下段（手入力）の講師を採用する |

- 下段を採用した席は、次の反映でも 1 行のまま（採用で手入力が残り、テンプレのその授業は取り下げとして記録する）。
- 上段を採用した席は、テンプレ由来の 1 行になる。
- 講師欄で「下段（手入力）の講師を採用する」を選んだ机は、次の反映でも手で置いた講師の 1 行のまま（2026-11-07 修正・INV-02/INV-03）。
  テンプレのその講師は、この机で取り下げたものとして机に記録する（`DeskCell.templateTeacherDeclined`）。記録は使い切りで、テンプレがこの机に
  別の講師を置くか講師を外した反映で消える（その後に同じ講師が戻れば新しいぶつかりとして 2 行）。旧 §H Q41（2026-11-01）の
  「手入力の講師を採用したあと再保存すると再び保留になる」はこの規則で置き換える。
  2026-11-07 夜、確認リスト ta-1 で「保存し直したら重複判定をし直して緑に」の案が出たが、懸案（ほかの曜日・時限だけ直した保存でも
  反映日以降の全週のその机が緑に戻り毎回採用し直しになる）と妥協案（そのコマのテンプレを変えた保存だけ判定し直す）を示した上で、
  オーナーは **「今のまま」** を選んだ。生徒の席の「下段（手入力）を採用する」も今のまま（予定数 −1 の取り下げを伴うため・同日オーナー選択「講師欄だけ」）。
- 講師欄で「上段（テンプレ）の講師を採用する」を選んだ机は、テンプレの講師の 1 行になる（記録は付けない）。
- 採用した手置き講師をあとで「休み」にした机は、次の反映でテンプレの講師が机に戻り、記録は消える（§2-4 の「別の講師はテンプレどおり置ける」と同じ。2026-11-07 オーナー確認「OK」）。

### 4-1-2. 「編集」で科目だけ変えたテンプレの授業を外したとき（2026-11-07 オーナー決定）

- テンプレの通常授業を「編集」で科目だけ変えた（例: 数→国）あと、その授業を削除・格納・休み・別の日や別の机へ移動しても、
  **テンプレの元の科目の授業はそのコマに戻らない**（機能フラグ templateDiffApply の ON／OFF とも同じ）。
  v1.5.704 で OFF の教室（本番）をこの形に直したあと、ON の教室（開発用・テスト教室）では削除で元の科目の授業が戻っていたため、
  オーナー指示「本番の教室での、削除したあと戻らなくなる方に揃えて」で揃えた。
- 科目を変えた授業の日を休日設定したときの未消化振替は、その時コマ表に入っていた科目（変えた後の科目）の 1 件だけ（テンプレの元の科目の分は立てない）。
- 丸ごと振替の付け替え（§3）で、元の日 D から移した先の日 D' へ移した**その生徒自身の D の授業**を D' で削除・格納したら、テンプレを保存しても
  D のテンプレのその生徒を D' に戻さない（2026-11-07 オーナー選択「戻さない」。ふだんの日の削除・上の科目を変えた授業と同じ）。
  付け替えを解除しても、その授業は D に戻らない（消したまま）。在庫からの振替・体験・別の生徒の手入力は対象外。
- 付け替えの作成で D から移した手入力（印 `wholeDayPairMovedFrom`）は、§9-21 の「D' に先にあった同じ生徒の手入力」に数えない
  （数えると作成しただけで D が休みになり未消化振替が +1 になる＝§3 の在庫中立に反する）。
  移した印が休み・解除・D' の中の移動で落ちても、授業 ID が D のテンプレの授業のままで振替元が D なら「その生徒自身の D の授業」とみなす
  （D' で休みにしても未消化はその時の科目の 1 件・D は「休)」のまま。v1.5.707。テンプレ由来のまま D' に展開した授業も同じ＝v1.5.708・§3「一部が来られない」）。
- D' で日付メニューの「生徒を空にする」を使ったら、D から付け替えた授業（展開したテンプレの授業・作成で移した授業）は D の日付の記録で止め、
  テンプレを保存しても戻さない（「戻さない」と同じ扱い・2026-11-07）。会計はふだんの日の「生徒を空にする」と同じ（付け替えの授業は振替として未消化へ +1・体験は返さず回数 −1）。
  付け替えを解除すると D' には D' 自身のテンプレが戻り、D の授業は戻らない。D 側で「生徒を空にする」を使っても D' の付け替えの授業は消さない。

### 4-2. 会計は 3 規則だけ

| # | 操作 | 会計 |
|---|---|---|
| 1 | 下段（手入力）を採用してテンプレの授業を取り下げた／§2-2 でテンプレの生徒を置かなかった | 予定数 −1（単発削除と同じ・決定記録 62） |

### 段 1. 出自の印（触れる INV: 02・03）
- 1-1 生徒・出欠記録・メモ・講師（机）を置くすべての経路で、置いた瞬間に印（テンプレ／手入力）が付く。QR 提出で自動で入った講師は手入力。§1-1 の各行に経路テストがある。

- 1-3 印は保存・読み込み・リアルタイム同期・Undo の後も変わらない。
- 1-4 印の無い旧データは §7 の推定で 1 回だけ付き、2 回目の読み込みで変わらない。
- 1-5 手入力の生徒名・講師名・メモが盤面で青字になる（「外)」などの前置きと背景は残る）。日程表・PDF・保護者 QR は青字にならない。
- 1-6 コマ表の「並び替え」は保留の机だけ固定し、テンプレ由来の机も動かす（§9-22 案 A）。テンプレ保存の直前にテンプレの並びへ戻す（`restoreTemplateDeskOrder`・不動点・保留固定・手入力の机は空いた番号へ）。並び替えた週の再マージで同じ講師が 2 机に出ず消えもしない（INV-01 マトリクス）。

### 段 2. 反映の規則（触れる INV: 01・02・03・05・06・12・13）
- 2-1 手入力の生徒がいる席にテンプレが生徒を置くと、その席が 2 行（上＝テンプレ／下＝手入力）になる。
- 2-2 テンプレ由来の席は新テンプレで置き直され、新テンプレに無ければ空く。2 行にならない。
- 2-3 同じコマに手入力の生徒 S があるとき、テンプレの S はどの机にも置かれず、予定数に数えず、確認画面に理由が出る。
- 2-4 同じ生徒の休み・振無休・出席・移) の記録があるコマに、テンプレはその生徒を置かない。
- 2-5 手置き講師の机にテンプレが別の講師を置くと講師欄だけ 2 行。テンプレ机が講師だけなら手入力の生徒は 1 行で残る。
- 2-6 手置き講師 X の机があるコマでテンプレが別の机に X を置いても、テンプレ側の机に X は置かれず、確認画面に理由が出る。同じ講師が同じコマの 2 机に出ない（INV-01 マトリクスに行を足す）。
- 2-10 テンプレ授業の科目・時間を手で変えた席は手入力として残り、テンプレが同じ席に置けば 2 行。
- 2-11 手入力の S が下の行にしか居ないとき、テンプレが S を置く席へ下の行の S が上がり 1 行になる（日程表と回数から消えない）。
- 2-12 手置き X の机にテンプレの別の講師 W と、別の机にテンプレの X が同時に来ても、X の机は X の 1 行のまま（W も B の X も置かれず理由が出る）。X は講師日程表に 1 回だけ出る。
- 2-7 同じ保存を 2 回しても、保存後に読み込み直しても盤面が変わらない（不動点）。
- 2-8 4 つの解決操作と講師の 2 択が §4-2 の 3 規則どおりに予定数・在庫を動かす（INV-06 の保存則監査 `auditTemplateLessonAccounting` が通る）。
- 2-9 「変えたコマだけ」の絞り込み（Q39）を使わなくても、手入力のある席は反映前後で変わらない。

### 段 3. 講師の休み（触れる INV: 01・02・03）
- 3-1 講師欄のメニューに「休み」があり、押すと机がグレーの「休」になる。
- 3-2 講師 X が休みのコマに、テンプレを反映しても X はどの机にも置かれない。
- 3-3 休みの机に別の講師を手で置ける。置いた講師は青字の手入力になり、休みの記録は残る。
- 3-4 休みの机の生徒は残り、机はグレーで講師なし。同じボタンをもう一度押すと解除され、次の反映でテンプレの講師が戻る。講師日程表・PDF・保護者 QR には休みを出さない（講師なしの机として出る）。
- 3-5 休みは 1 コマごと。一括ボタンは無い。コマ表で講師を消した記録は休みとは別のまま動く。

### 段 4. 丸ごと振替の付け替え（触れる INV: 02・05・06・12）
- 4-1 丸ごと振替の移動先に、移動元と違う曜日は選べない。
- 4-2 D → D' の組が 1 本保存され、テンプレを反映しても（D を休日設定にしても）組は消えない。
- 4-3 テンプレで D に新しく割り振った授業が、反映後に D' の同じ時限・同じ机番号へ「振)」で出て、D には「休)」が出る。
- 4-4 D' 自身のテンプレの授業は組がある間は展開されず（消去・在庫に入れない）、D のテンプレだけが出る。組を消すと D' の自分のテンプレが戻る。
- 4-5 D' で一部の生徒を休みにすると振替在庫が 1 増える。付け替え自体では在庫は動かない。
- 4-6 D' に先にあった手入力の席は 2 行になる。
- 4-7 保護者 QR の日程（Functions 側）が盤面と同じ結果になる（パリティテスト）。
- 4-8 予定数は移動元 D の月で数える。
- 4-9 休日設定の日の振替を別の日へ置いた後にテンプレでその授業が無くなったら、置いた振替は消え（在庫に入れない）、確認画面に名前が出る。

### 段 5. 移行（触れる INV: 02・06）
- 5-1 開発用教室で、移行前後に生徒×科目の在庫残数と予定数が変わらない。
- 5-2 開発用・テスト教室の既存の保留と別曜日の丸ごと振替を作り直す。片づけの前後で授業・記録・在庫が消えない（消える件数 0・組み直せないものは一覧で報告）。
- 5-3 テスト教室で同じ確認を通してから、本番の展開をオーナーが決める。
- 5-4 §H を「旧仕様（2026-11-05 まで）」として畳み、`docs/spec-index.md` の正本をこの文書へ差し替える。
