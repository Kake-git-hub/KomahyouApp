## 0. 目的と置き換える範囲

- **目的**: テンプレを反映したときの盤面を、**「出自の印」と 4 本の規則**だけで決める。場合分けを積み上げない。
- **置き換える**: §H の Q21〜Q42（何を捨てるかは §6）。
- **変えない**: Q1（反映日より前は触らない）・反映日の既定・保存前の自動バックアップとレポート PDF（Q32-2・-3）・
  保留データの置き場（Q24）・2 行の机では出席を付けない（Q27）・1 行に戻る条件（Q28）・フラグ（Q33）。
- **反映の範囲**: 反映日以降の、盤面に生成済みの週の**全コマ**。毎回すべて当て直す（§6 Q39）。

## 1. 用語

| 用語 | 意味 |
|---|---|
| 出自の印 | 盤面のデータを**置いた瞬間**に記録する 2 値。`テンプレ`／`手入力`。種別（通常・振替など）から推測しない。 |
| テンプレ由来 | 印が `テンプレ`。テンプレの展開で置かれたもの。反映のたびに新テンプレで置き直す。 |
| 手入力データ | 印が `手入力`。人の操作で置いたもの（QR 提出で自動で入った講師も含む・§9-13）。反映で**消さない・動かさない**。 |

## 2. 反映の規則

当てる順番は **丸ごと振替（§3）→ 休み → 生徒の一意 → 講師の一意 → 席**。前の規則で置かないと決まったものは、後の規則で置かない。

### 2-1. 席の規則（基本）

| 反映先の席の今 | 新テンプレがその席に置くもの | 結果 |
|---|---|---|
| 空 または テンプレ由来 | 生徒 | テンプレの生徒（1 行） |
| 空 または テンプレ由来 | なし | 空（テンプレ由来は外れる） |
| 手入力の生徒・メモ | 生徒 | **2 行**（上＝テンプレ／下＝手入力） |
| 手入力の生徒・メモ | なし | 手入力のまま 1 行 |
| 休みの記録だけ（別の生徒） | 生徒 | テンプレの生徒を置く。記録は残す（§9-10） |

- 机の突き合わせは**同じコマの机番号どうし**。テンプレ由来の机はコマ表の「並び替え」で動かさない（並び替えで動くのは手入力の机だけ。テンプレの並びはテンプレ編集の並び替えで変える・§9-5）。
- テンプレ机が講師だけ（生徒なし）なら、席の手入力生徒はそのまま残る（2 行にならない・決定 6）。

### 2-2. 生徒の一意（1 本規則）

- 同じコマ（日付×時限）に、**手入力の生徒 S** と**テンプレの同じ生徒 S** がぶつかったら、**手入力が勝つ**。テンプレの S はそのコマのどの机にも置かない。
- 前のテンプレ由来の S は「テンプレ由来」なので、新テンプレの S に置き直されるだけ（ぶつからない）。
- 「勝つ」根拠になる手入力の S は**上の行（机）に生きているもの**。手入力の S が**緑の下の行にしか居ない**ときは、下の行の S をテンプレが S を置こうとした席へ**自動で上げて 1 行**にする（§9-14・下の行は盤面だけの表示なので、日程表と回数から消さない）。上げる席が無ければ置かずに理由を出す。
- 置かなかったテンプレの S は予定数に数えない（§4 会計規則 1 と同じ扱い）。保存前の確認画面に「手入力が先にあるため置かない」と出す。
- これで INV-12（同じ生徒は同じコマに 1 か所）が構造で成り立つ。

### 2-3. 講師の一意（1 本規則）

| 机の講師の今 | 新テンプレの講師 | 結果 |
|---|---|---|
| 空・テンプレ由来 | X | X（テンプレに揃える） |
| 手置き講師 Y | X（Y と別人） | **講師欄だけ 2 行**（上＝X／下＝Y）。席は §2-1 で別に決める。 |
| 手置き講師 Y | なし | Y のまま |
| 講師の削除記録（X） | X | 置かない（空のまま） |
| 講師 X の休み | X | 置かない（§2-4） |

- **同じ講師は 1 コマに 1 机**（INV-01）。手置き講師 X の机 A があるのに、テンプレが別の机 B に X を置くときは、
  **手入力が勝つ**＝机 B に X を置かない（B のテンプレ生徒は置く・講師欄は空）。確認画面に理由を出す（§9-1）。
- 机 A（手置き X）にテンプレが別の講師 W を置き、さらに別の机 B に X を置く形では、**机 A の講師は X のまま**（W は置かず講師欄は 1 行・B にも X を置かない）。理由を確認画面に出す（§9-15）。
- QR 提出で自動で入った講師も手置き講師と同じ（手入力・青字・§9-13）。旧 Q21-9 例外 1（QR の講師を外す）は廃止。

### 2-4. 休みの規則（休みが勝つ）

| 対象 | 休みの記録 | テンプレが置こうとするもの | 結果 |
|---|---|---|---|
| 生徒 S | S の休み・振無休・出席・「移)」がそのコマにある | S | 置かない（記録が勝つ・実績は記録に残る）。記録は**そのコマだけ**に効く（同じ日の別の時限に S を置くことは止めない・§9-16） |
| 講師 X | X の休みがそのコマにある | X（どの机でも） | 置かない。机はグレーの「休」 |
| 講師 X | 同上 | その机の生徒 | 置く（机はグレー・講師なし・別の講師で上書き可）（§9-7） |

- 講師の休みは**盤面の新しい「休み」ボタン**で付ける（講師欄のメニュー・**1 コマごと**・「この日全部」の一括ボタンは作らない・§9-4）。別の講師を手で置いて上書きできる（休みの記録は残り、テンプレの X は引き続き置かない）。
- 解除は同じボタンをもう一度押す。休んだ講師本人をその机に手で置き直したときも自動で解除する（§9-19）。記録は盤面の週と同じ期間残る。操作ログには残さない（§9-8）。
- 見せる場所は**コマ表の画面だけ**。講師日程表・コマ表 PDF・保護者 QR には出さない（そのコマは講師なしの机として出る）（§9-8）。
- コマ表で講師を消した記録（§1-1 #14）は休みとは別のまま残す（§9-8）。
- 置き場の一案（実装側の判断）: 生徒の出欠記録（`statusSlots`）とは分け、机に任意項目 `teacherRest: { teacherId, origin: 'manual' }` を持つ。
  判定は「日付×時限×講師 ID」で引く（席を消費しない・講師の一意判定と同じ鍵）。

## 3. 丸ごと振替（日付の付け替え）

| 項目 | 規則 |
|---|---|
| 曜日 | **同じ曜日だけ**。別の曜日は選べない。 |
| 記録 | 「移動元の日 D → 移動先の日 D'」の**組 1 本**を教室データに残す。個々の振替を正本にしない。 |
| テンプレ反映 | D と D' の組は変わらない（D を休日設定にしていても）。**D の新テンプレの授業は D' の同じ時限・同じ机番号へ自動で展開**する。 |
| 見せ方 | D は「休)」、D' は「振)」（今と同じ）。D' の授業の出自は `テンプレ（付け替え）`＝青字にしない。 |
| D' のテンプレ | D' 自身のテンプレの授業は展開しない（**消去・在庫に入れない**。今の丸ごと振替の振替先の処分と同じ・§9-2）。組がある間、D' には D のテンプレだけが出る。 |
| D' の手入力 | D' に先に置いた手入力は §2-1 のとおり 2 行。 |
| 一部が来られない | D' でその生徒を「休み」にする → 振替在庫へ（通常の休みと同じ会計）。 |
| 在庫 | 付け替えそのものは在庫中立（`spec-makeup-stock.md` §B-2-3 と同じ）。 |
| 月をまたぐ | 予定数は移動元 D の月で数える（§9-3）。 |
| 解除 | 組を消すと D へ戻る。作成で D から D' へ移した手入力も D へ戻す（§9-20）。D' に記録（出席・休み）があるときは解除を止める。 |
| D' に同じ生徒の手入力 | D の S の授業は D' に置かず（§2-2）、D の S は「休み」として未消化振替へ（振替先は出さない・§9-21）。 |
| 保護者 QR | Functions 側の日程計算（`functions/src` の parentSchedule・パリティテスト）も組から同じ計算をする。 |
| 休日の振替 | 休日設定の日の授業の振替を別の日へ置いた後、テンプレでその授業が無くなったら、置いた振替は**今どおり消す**（未消化にも残さない・確認画面に名前を出す・旧 Q40-1 を残す・§9-12）。 |

## 4. 解決操作と会計

### 4-1. 解決操作（今のメニューをそのまま使う）

| 場所 | 操作 |
|---|---|
| 2 行の席 | 上段（テンプレ）を採用する／下段（手入力）を採用する／下段（手入力）を移動する／下段（手入力）を削除する |
| 2 行の講師欄 | 上段（テンプレ）の講師を採用する／下段（手入力）の講師を採用する |

- 下段を採用した席は、次の反映でも 1 行のまま（採用で手入力が残り、テンプレのその授業は取り下げとして記録する）。
- 上段を採用した席は、テンプレ由来の 1 行になる。

### 4-2. 会計は 3 規則だけ

| # | 操作 | 会計 |
|---|---|---|
| 1 | 下段（手入力）を採用してテンプレの授業を取り下げた／§2-2 でテンプレの生徒を置かなかった | 予定数 −1（単発削除と同じ・決定記録 62） |
| 2 | 上段（テンプレ）を採用して手入力の振替・講習を外した | 在庫へ戻す。手動追加・体験・増コマは戻さない。 |
| 3 | 記録（出席・休み・振無休・移)）のある席 | 採用の対象外（記録は動かさない） |

## 5. 表示

| 表示 | 規則 |
|---|---|
| 青字 | 出自が `手入力` の生徒名・講師名（手置き・QR）・メモ（§9-9）。 |
| 緑 2 行 | 2 行の席・講師欄。上＝テンプレ、下＝手入力。 |
| グレー「休」 | 講師の休みの机（講師なし）。別の講師を置けば通常表示。 |
| 既存の色との優先 | 文字色は青が勝つ。「外)」・体験・振)・休) は文字の前置きと背景で残す（§9-9）。 |
| 日程表・PDF・保護者 QR | 青字・緑・講師の休みのグレーは盤面だけ。2 行の下段は盤面だけ（INV-13）。 |

| 1 | 手置き講師 X の机 A があるのに、テンプレが別の机 B に X を置く | **手入力が勝つ**。B に X を置かない（確認画面に理由）。決定記録 66（講師の 2 行）は取り消し。 |
| 2 | 丸ごと振替の移動先 D' にテンプレが展開される日 | **今の丸ごと振替と同じ**。D' 自身のテンプレの授業は消去（未消化に入れない）し、D のテンプレを出す。 |
| 3 | 月をまたぐ丸ごと振替の予定数 | **移動元 D の月**。 |
| 4 | 講師の休みの単位 | **1 コマごと**。「この日全部」の一括ボタンは不要。 |
| 5 | 机番号の突き合わせと並び替え | **テンプレ由来の机はコマ表の並び替えで動かさない**（並び替えはテンプレ編集だけ）。 |
| 6 | 既存の保留・別曜日の丸ごと振替 | **作り直す**。開発用・テスト教室とも確認なしでよい。 |
| 7 | 休みの講師の机の生徒 | **残す**。机はグレーで講師なし、別の講師で上書きできる。 |
| 8 | 講師の休みの出し先／解除／削除記録 | **コマ表の画面だけ**／**同じボタンをもう一度**（記録は週と同じ期間・操作ログなし）／**削除記録は休みと別のまま**。 |
| 9 | 青字の範囲と色の優先 | **生徒名・手置き講師名・メモを青**。文字色は青が勝ち、「外)」などは前置きと背景で残す。 |
| 10 | 別の生徒の休みの記録だけがある席にテンプレが別の生徒を置く | **置く**。記録はそのまま残す。 |
| 11 | テンプレ授業の科目・時間を手で変えたもの | **手入力**（青字・反映で残る）。 |
| 12 | 休日設定の日の振替の追従 | **今どおり消す**（未消化にも残さない）。旧 Q40-1 を残す。 |
| 13 | QR 提出で自動で入った講師 | **手入力と同じく守る**（講師欄 2 行・青字）。出自の印は 2 値になる。 |
| 14 | 手入力の S が緑の下の行にしか居ないのに、テンプレが別の机に S を置く（監査 要修正-1） | **下の行の S をテンプレの席へ自動で上げる**（1 行にする）。 |
| 15 | 手置き X の机 A にテンプレが別の講師 W、別の机 B に X（監査 要確認 5） | **机 A の講師は X のまま**。W を置かず、B にも X を置かない。 |
| 16 | 同じ日の別の時限に S の休みの記録があり、テンプレで S の時限を変える（監査 要確認 6-1） | **そのコマだけ**。新しい時限に S を置く（休みと授業の両方がその日に残る）。 |
| 17 | 別の日へ動かして元の日へ戻した授業（監査 要確認 6-2） | **手入力のまま**（テンプレに追従しない）。 |
| 18 | 手置き X の机 A にテンプレの W、別の机 B にテンプレの X、かつ X がそのコマで休み | **休みの X はテンプレに居ないものとして扱う**。B に X は置かず、机 A は上＝W／下＝X の 2 行（§9-15 の「X のまま」は当てない）。 |
| 19 | 休みにした机に、休んだ講師本人を手で置き直した | **自動で休みを解除する**（記録を消す・グレーが消える・次の反映でテンプレどおり）。 |
| 20 | 付け替えの作成で D から D' へ移した手入力は、解除でどうするか（監査 要確認-1） | **D へ戻す**（作成→解除で元の形に戻る。D' のその席に記録があれば解除を止める）。 |
| 21 | D' に同じ生徒 S の手入力が先にあり、D の S の授業が D' に置かれない（監査 要確認-4） | **D の S は「休み」として未消化振替に入れる**（振替先は出さない。保護者ページは「D お休み」だけ）。 |

## 10. 実装タスク（受け入れ条件つき・段階順）

各段は開発用教室で確認リストを通してから次へ。各段にユニットテストを同じコミットで添える。

### 段 1. 出自の印（触れる INV: 02・03）
- 1-1 生徒・出欠記録・メモ・講師（机）を置くすべての経路で、置いた瞬間に印（テンプレ／手入力）が付く。QR 提出で自動で入った講師は手入力。§1-1 の各行に経路テストがある。
- 1-2 テンプレの授業を同じ日の別の机へ動かしても印は `テンプレ` のまま。別日へ移動した移動先は `手入力`。
- 1-3 印は保存・読み込み・リアルタイム同期・Undo の後も変わらない。
- 1-4 印の無い旧データは §7 の推定で 1 回だけ付き、2 回目の読み込みで変わらない。
- 1-5 手入力の生徒名・講師名・メモが盤面で青字になる（「外)」などの前置きと背景は残る）。日程表・PDF・保護者 QR は青字にならない。
- 1-6 コマ表の「並び替え」はテンプレ由来の机を動かさない。

### 段 2. 反映の規則（触れる INV: 01・02・03・05・06・12・13）
- 2-1 手入力の生徒がいる席にテンプレが生徒を置くと、その席が 2 行（上＝テンプレ／下＝手入力）になる。
- 2-2 テンプレ由来の席は新テンプレで置き直され、新テンプレに無ければ空く。2 行にならない。
- 2-3 同じコマに手入力の生徒 S があるとき、テンプレの S はどの机にも置かれず、予定数に数えず、確認画面に理由が出る。
- 2-4 同じ生徒の休み・振無休・出席・移) の記録があるコマに、テンプレはその生徒を置かない。
- 2-5 手置き講師の机にテンプレが別の講師を置くと講師欄だけ 2 行。テンプレ机が講師だけなら手入力の生徒は 1 行で残る。
- 2-6 手置き講師 X の机があるコマでテンプレが別の机に X を置いても、テンプレ側の机に X は置かれず、確認画面に理由が出る。同じ講師が同じコマの 2 机に出ない（INV-01 マトリクスに行を足す）。
- 2-10 テンプレ授業の科目・時間を手で変えた席は手入力として残り、テンプレが同じ席に置けば 2 行。
- 2-11 手入力の S が下の行にしか居ないとき、テンプレが S を置く席へ下の行の S が上がり 1 行になる（日程表と回数から消えない）。
- 2-12 手置き X の机にテンプレの別の講師 W と、別の机にテンプレの X が同時に来ても、X の机は X の 1 行のまま（W も B の X も置かれず理由が出る）。X は講師日程表に 1 回だけ出る。
- 2-7 同じ保存を 2 回しても、保存後に読み込み直しても盤面が変わらない（不動点）。
- 2-8 4 つの解決操作と講師の 2 択が §4-2 の 3 規則どおりに予定数・在庫を動かす（INV-06 の保存則監査 `auditTemplateLessonAccounting` が通る）。
- 2-9 「変えたコマだけ」の絞り込み（Q39）を使わなくても、手入力のある席は反映前後で変わらない。

### 段 3. 講師の休み（触れる INV: 01・02・03）
- 3-1 講師欄のメニューに「休み」があり、押すと机がグレーの「休」になる。
- 3-2 講師 X が休みのコマに、テンプレを反映しても X はどの机にも置かれない。
- 3-3 休みの机に別の講師を手で置ける。置いた講師は青字の手入力になり、休みの記録は残る。
- 3-4 休みの机の生徒は残り、机はグレーで講師なし。同じボタンをもう一度押すと解除され、次の反映でテンプレの講師が戻る。講師日程表・PDF・保護者 QR には休みを出さない（講師なしの机として出る）。
- 3-5 休みは 1 コマごと。一括ボタンは無い。コマ表で講師を消した記録は休みとは別のまま動く。

### 段 4. 丸ごと振替の付け替え（触れる INV: 02・05・06・12）
- 4-1 丸ごと振替の移動先に、移動元と違う曜日は選べない。
- 4-2 D → D' の組が 1 本保存され、テンプレを反映しても（D を休日設定にしても）組は消えない。
- 4-3 テンプレで D に新しく割り振った授業が、反映後に D' の同じ時限・同じ机番号へ「振)」で出て、D には「休)」が出る。
- 4-4 D' 自身のテンプレの授業は組がある間は展開されず（消去・在庫に入れない）、D のテンプレだけが出る。組を消すと D' の自分のテンプレが戻る。
- 4-5 D' で一部の生徒を休みにすると振替在庫が 1 増える。付け替え自体では在庫は動かない。
- 4-6 D' に先にあった手入力の席は 2 行になる。
- 4-7 保護者 QR の日程（Functions 側）が盤面と同じ結果になる（パリティテスト）。
- 4-8 予定数は移動元 D の月で数える。
- 4-9 休日設定の日の振替を別の日へ置いた後にテンプレでその授業が無くなったら、置いた振替は消え（在庫に入れない）、確認画面に名前が出る。

### 段 5. 移行（触れる INV: 02・06）
- 5-1 開発用教室で、移行前後に生徒×科目の在庫残数と予定数が変わらない。
- 5-2 開発用・テスト教室の既存の保留と別曜日の丸ごと振替を作り直す。片づけの前後で授業・記録・在庫が消えない（消える件数 0・組み直せないものは一覧で報告）。
- 5-3 テスト教室で同じ確認を通してから、本番の展開をオーナーが決める。
- 5-4 §H を「旧仕様（2026-11-05 まで）」として畳み、`docs/spec-index.md` の正本をこの文書へ差し替える。
