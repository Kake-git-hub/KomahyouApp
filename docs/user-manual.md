# コマ表アプリの使い方

> この文書は教室の利用者（室長・スタッフ）向けの使い方の説明です。画面に出ている言葉（ボタン名・メニュー名）で書いています。
> 「質問・要望」からの質問に自動で回答するときの根拠にも使います。
> 一部の教室だけで試験中の機能は載せていません。ここに無いことは「質問・要望」から聞いてください。

## 0. はじめに

### 0-1. このアプリでできること

- 1 週間ごとのコマ表（盤面）を作り、生徒ごと・講師ごとの日程表を印刷・共有できます。
- 毎週くり返す通常授業は「通常授業テンプレート」に登録しておくと、各週へ自動で並びます。
- 欠席の振替と、季節講習（特別講習）の残り回数をアプリが数えます。
- 講習の希望は、生徒・保護者と講師がスマホの QR コードから提出できます。

### 0-2. ログインと教室

- ログインはメールアドレスとパスワードです。ログイン画面の「パスワードリセットまたはパスワード変更」からパスワードを変えられます。
- 室長は自分の教室だけを開けます。開いている教室の名前は画面上部に出ます。変更は**いま開いている教室**にだけ入ります。
- インターネットにつながっていないときはアプリを使えません（「オフラインのため使用できません」と出ます）。つながってから開き直してください。
- 同じ教室を 2 台の端末で同時に編集しないでください（第 9 章）。

### 0-3. 困ったときは

- コマ表と日程表のどちらにも、右上に「質問・要望」ボタンがあります。使い方の質問・要望・不具合をそのまま送れます（第 10 章）。

## 1. 画面の全体像

### 1-1. メニューの 5 画面

| 画面 | ここでやること |
|---|---|
| コマ表 | 週ごとの盤面。授業を置く・動かす・欠席や振替を記録する。日程表・印刷・共有もここから開く |
| 基本データ | 生徒・講師・教室データ（定休日・机数）の登録 |
| 特別講習データ | 講習の名前と期間の登録 |
| 自動割振ルール | 自動割振のときに守るルールの設定 |
| バックアップと初期設定 | 手動バックアップの書き出し・読み込み、復元、Excel の取り込み・出力、初期設定 |

### 1-2. コマ表（盤面）の見方

- 表は「日付 × 時限（1〜5 限）× 机」です。1 つの机に講師 1 人と生徒 2 人まで座ります。
- 週の移動は「◀ 前週」「今日」「次週 ▶」と、日付を選ぶカレンダー（表示したい日付を選択）で行います。
- 盤面の左右にはパネルがあり、机をクリックすると「選択中の机」「同じコマの他の机」の中身が出ます。「通常残 / 未解決一覧」には注意が必要な生徒が並びます。
- 授業の種類は色ではなく、名前の前のラベルで見分けます。

| 表示 | 意味 |
|---|---|
| 通) | 通常授業（テンプレートどおりの毎週の授業） |
| 振) | 振替（欠席や休日で生まれた振替を置いたコマ。元の日付が添えられます） |
| 講) | 講習（特別講習のコマ。授業時間が 60 分・45 分のときは「講)小5算60」のように分数が付きます） |
| 休 ＋日付 | 休み（振替あり）。日付はその休みの振替先です。振替先がまだ無いときは日付が付きません |
| 振無休 | 振替なしの休み |
| 出 | 出席済み |
| 赤い文字 | 注意が必要なコマ。手動追加した生徒、講師がいない机、ルール違反など。理由はカーソルを合わせると出ます |

- 別の日へ動かした通常授業の元のコマや、休日設定で消えた授業も「休」＋日付の形で残ります（その日は授業を受けていない、という記録です）。
- 「増コマ」は通常授業に足した追加の 1 コマ、「体験授業」は名簿に無い体験の生徒のコマです。

### 1-3. コマ表のツールバー

| ボタン | 働き |
|---|---|
| 保存／最新データ | 赤い「保存」は未保存の変更があるとき。押すとサーバーへ保存します。緑の「最新データ」は保存済みの状態です。保存中は「保存中…」になります |
| 元に戻す／やり直し | 直前の操作を取り消す・やり直す |
| 直前の状態に戻す | 大きな操作（テンプレ保存・一括削除など）の直後に、その前の状態へ戻す |
| 通常授業テンプレ作成 | 通常授業テンプレートの編集モードに入る（第 3 章） |
| 未消化講習 | 未消化の講習の一覧を開く（第 6 章）。件数が付きます |
| 未消化振替 | 未消化の振替の一覧を開く（第 5 章）。件数が付きます。振替を置いている間は「振替移動中」になります |
| 生徒日程／講師日程 | 日程表を別タブで開く（第 8 章） |
| PDF出力 | 盤面を PDF にする（第 8 章） |
| 並べ替え | 生徒の並び順を変える |
| エクセル取込／エクセル現状出力 | テンプレート編集モードのときだけ。通常授業テンプレートの Excel 取り込み・出力 |
| 講師日程共有 | 講師に見せる閲覧専用のページの QR とリンクを出す（第 8 章） |
| 質問・要望 | 開発者へ質問・要望・不具合を送る（第 10 章）。新しい回答があると件数が付きます |

## 2. 基本データ（生徒・講師・教室データ）

基本データ画面にはタブが 3 つあります：生徒／講師／教室データ。生徒と講師の表は並べ替えと絞り込みができます。

### 2-1. 生徒の登録

1. 基本データ画面を開き、「生徒登録」で氏名・表示名・メール・入塾日・退塾日・生年月日を入れて「追加」を押します。外部生なら「外部生」に印を付けます。
2. 学年は生年月日から自動で決まります（4 月 1 日で学年が上がる。1〜3 月生まれは 1 学年上）。学年欄は入力しません。
3. 受講科目は通常授業テンプレートで決まります（第 3 章）。
4. 入塾日より前の日の盤面にはまだ並びません。入塾日の週から自動で並びます。
5. 登録を直したいときは行の「編集」を押します。氏名を直すと、盤面と日程表の名前も新しい名前に変わります。

### 2-2. 生徒の退塾

- 生徒の行の「退塾」を押すと確認画面が出て、確定すると**押した日が退塾日**になります。退塾日のその日から非在籍の扱いです。
- 退塾すると、今日以降の盤面からその生徒の通常授業・手で置いた講習や振替・今日以降の出欠記録が消えます。昨日までの記録は残ります。未消化の振替・講習は戻りません。
- **退塾は元に戻せません**（退塾日を消しても消えたコマは戻りません）。直後なら「直前の状態に戻す」で保存前に限って戻せます。
- 退塾した生徒は「退塾生徒」の一覧に移ります。退塾後の行は編集できません（生年月日の修正だけはできます）。
- 退塾予定日を先の日付で入れた場合は、その日が来るまで自由に直せます。その日が来ると自動で非在籍になります。
- 高校 3 年生は 3 月 31 日まで在籍で、4 月 1 日から自動で卒業（退塾）扱いになります。
- 「退塾生徒」の一覧にある「削除」は、名簿からデータ上も消す操作です。ログインのパスワードを求められ、元に戻せません。データを残したいだけなら削除せず退塾のままにしてください。

### 2-3. 講師の登録

1. 「講師登録」で氏名・表示名・メール・入塾日・退塾日・担当科目を入れて「追加」を押します。
2. 担当科目は「科目 ＋ 担当できる上限の学年」で登録します。選んだ学年以下の生徒を担当できます。
3. 休職などで一時的に外したいときは退塾日を入れます。戻るときは退塾日を消します。講師は退塾日の当日までは在籍です。
4. 退職した講師は「非在籍講師表示」で見られます。削除はパスワードを求められ、元に戻せません。

### 2-4. 教室データ（定休日・机数）

- 「教室データ」タブで、毎週の定休日（曜日）と机数を変えられます。
- 祝日や臨時の休みは基本データではなく、**コマ表の日付メニューの「休日設定」**で設定します（第 4 章）。

## 3. 通常授業（テンプレート）

### 3-1. 考え方

- 毎週くり返す通常授業は「通常授業テンプレート」に 1 回登録します。登録した曜日・時限・机に、在籍している週だけ自動で並びます。
- 「月 4 回」のような回数の上限はありません。授業の回数は、その月にその曜日が来た回数です。第 5 週も他の週と同じように並びます。5 週目を休みにしたいときは、その日を「休日設定」にするか、その日の授業を手で消します。
- 祝日は特別扱いしません（平日と同じように並びます）。休みにする日は「休日設定」で指定します。

### 3-2. テンプレートの登録・変更

1. コマ表の「通常授業テンプレ作成」を押すと、編集モードになります（ツールバーが切り替わります）。
2. 曜日 × 時限 × 机のマスに講師 1 人と生徒 2 人まで、科目と授業時間（90 分・60 分・45 分。選ばなければ 90 分）を置きます。空席をクリックして生徒を選びます。
3. 入塾日がまだ来ていない生徒もテンプレートに置けます（盤面に出るのは入塾日の週からです）。退塾した生徒は置けません。
4. 定休日のマスには置けません。
5. 「反映開始日」を確認します。はじめは来週の月曜日になっています。今日より前の日は選べません。
6. 「保存」を押すと確認画面が出ます。何机が変わるか、手で置いていたコマがどう扱われるかが件数で表示されるので、確認してから保存します。保存の直前にバックアップが自動で取られます。
7. 「コマ表に戻る」で編集モードを終えます。保存していない下書きは盤面に反映されません。
8. 「テンプレを空にする」はテンプレートの下書きを全部消します。

### 3-3. 保存するとどうなるか

- **反映開始日より前の盤面は一切変わりません**（講師・生徒・出欠・メモすべてそのまま）。
- 反映開始日以降の週に新しいテンプレートが並びます。生成されるのはその年度の 3 月 31 日までです。年度が替わるときは新しいテンプレートを作って保存します。
- 設定済みの定休日と、休日設定で開けた日（強制開校日）は、テンプレート保存で消えません。
- 反映開始日以降に手で置いていた振替・講習・出欠記録の扱いは、保存前の確認画面に件数つきで表示されます。確認画面の内容に従ってください。
- 保存した直後なら「直前の状態に戻す」で保存前の盤面へ戻せます。

### 3-4. その週だけの変更

- 「今週だけ時間を変える」「今週だけ机を替える」は、テンプレートではなく**盤面で直接動かします**（第 4 章）。盤面で動かした内容はテンプレートに影響せず、来週以降は変わりません。
- 盤面で別の日へ動かした通常授業は、その回だけの振替（振)）になります。元のコマには「休」と移動先の日付が残ります。
- 曜日・時間を今後ずっと変えるときは、テンプレートを直して保存します。

### 3-5. Excel での出し入れ

- テンプレート編集モードの「エクセル現状出力」でテンプレートを Excel に出せます。「エクセル取込」で Excel からテンプレートの下書きへ読み込めます。読み込んだ後は通常どおり「保存」で盤面へ反映します。

## 4. 盤面の日々の操作

### 4-1. 生徒をクリックしたときのメニュー

| ボタン | 働き |
|---|---|
| 休み | 欠席。コマは消さず「休」と表示し、その生徒の未消化振替が 1 回たまります。席は空くので、同じ席に別の生徒を置けます |
| 振無休 | 振替をしない欠席。「振無休」と表示し、振替はたまりません |
| 出席 | 出席を記録します。「出」と表示します |
| 休み解除／振無休解除／出席解除 | 記録を取り消して、置いただけの状態に戻します |
| 移動 | 別の机・別の日へ動かします。長押しして引っぱる（ドラッグ）でも動かせます |
| 席を入れ替え | 同じ机の 2 人の席を入れ替えます |
| 削除 | そのコマを盤面から消します。未消化には戻りません。通常授業なら日程表の予定数が 1 減り、講習なら希望数が 1 減ります |
| ストックへ戻す | 置いた振替・講習を未消化へ戻します（第 5・6 章） |
| メモ | その席にメモを書きます |

- 手動で追加した生徒は赤い文字で表示され、カーソルを合わせると「手動追加」と出ます。

### 4-2. 空いている席をクリックしたとき

- 「生徒追加」「既存生徒追加」で名簿の生徒を選んで、通常・振替・講習・増コマのいずれかで置けます。講習を手で置くときは特別講習（期間）・科目・授業時間を選びます。
- 「体験授業」で名簿に無い体験の生徒を置けます。
- 「メモ」でその席にメモを書けます。

### 4-3. 講師をクリックしたとき

- 「講師削除」でその机の講師を外します。外した講師はテンプレート保存でも戻りません。
- 「講師だけ入れ替え」で講師を別の講師に替えます（生徒はそのまま）。

### 4-4. 日付をクリックしたときのメニュー

| ボタン | 働き |
|---|---|
| 丸ごと振替 | その日の全コマ（講師・生徒・メモ）を、同じ顔ぶれのまま別の日へ移します。押すと振替先を選ぶモードになるので、移す先の日付をクリックし、件数の確認を見て実行します。元の日の通常授業は「休」＋移動先の日付で残ります。元の日か移す先に出欠記録が 1 件でもあると実行できません |
| 休日設定 | その日を休みにします。その日に通常授業があった生徒は全員、未消化振替に自動でたまります。置いてあった講習は未消化講習へ戻ります。その日の授業は「休」の記録として残ります。もう一度押すと休みを解除し、記録の生徒を元の席へ戻します（確認が出ます） |
| 生徒を空にする | その日の生徒を全員消します。在庫から置いた振替・講習は未消化へ戻ります。通常授業・増コマ・手動追加は戻らず、予定数が 1 減ります |

- 休日設定にした日は灰色で表示され、授業は置けません。講師名も隠れます。
- 定休日に授業をしたい日は、その日を「休日設定」で開校日（強制開校日）にできます。

### 4-5. 元に戻す

- 「元に戻す」「やり直し」で 1 操作ずつ戻せます。
- 一括の操作（テンプレ保存・丸ごと振替・休日設定・生徒を空にする・復元など）の直後は「直前の状態に戻す」でまとめて戻せます。いずれも**保存する前**に限ります。保存した後の変更を戻したいときは第 9 章の復元を見てください。

## 5. 欠席と振替

### 5-1. 振替がたまるとき

- 生徒を「休み」にしたとき（生徒 × 科目ごとに 1 回）。
- 日付を「休日設定」にしたとき（その日に通常授業があった生徒全員）。
- 置いてあった振替コマを「休み」にしたとき（元の休みの分が未消化に戻ります）。
- 運用を始めたときの繰り越し分は、初期設定で登録した分がたまっています。
- 同じ日・同じ時限に同じ生徒が 2 コマ以上あると、余った分が「同時間帯の重複」として振替にたまります。

### 5-2. 残りの見方

- ツールバーの「未消化振替」を押すと、生徒 × 科目ごとの残り回数と、元のコマ（休んだ日付・時限と理由）の一覧が開きます。ボタンの数字が未消化の合計です。
- 一覧は盤面を操作しても開いたままです。

### 5-3. 振替を置く

1. 「未消化振替」の一覧で生徒（と元のコマ）を選びます。ボタンが「振替移動中」になります。
2. 盤面の空いている席をクリックすると、そこに振)として置かれ、残りが 1 減ります。元のコマの「休」には振替先の日付が付きます。
3. 同じコマに同じ生徒がすでにいる席には置けません。
4. 自動でまとめて置くこともできます（第 7 章）。

### 5-4. 置いた振替を戻す・消す

- 置いた振替をクリックして「ストックへ戻す」を押すと、未消化に戻って残りが 1 増えます。
- 「削除」はそのコマを消すだけで、未消化には戻りません（もうその振替はやらない、という操作です）。
- 未消化振替の一覧の × で消した振替は元に戻せません。消す前に確認してください。
- 「休み」を取り消すときは、そのコマの「休み解除」を押します。たまった振替も 1 減ります。

### 5-5. 日程表での確認

- 生徒日程表の振替欄に「科目 元の日付 → 振替先」が並びます。振替先がまだ無いものは「未定」と出ます。組み忘れの確認に使えます（第 8 章）。

## 6. 特別講習（季節講習）

### 6-1. 講習の作成

1. 特別講習データ画面の「新しい特別講習を作成」で講習名と期間を入れ、「特別講習を作成」を押します。
2. 同じ名前の講習は作れません。期間が他の講習と 1 日でも重なる講習も作れません。
3. 作った講習は「特別講習一覧」で編集・削除できます。

### 6-2. 希望の受け付け（生徒・保護者）

1. コマ表の「生徒日程」で生徒日程表を開き、生徒を選ぶと、講習期間が表示範囲に入っているときに**その生徒専用の QR コード**が出ます。これを保護者に渡します（印刷した日程表にも載ります）。
2. 保護者がスマホで QR を開くと、本人用の提出ページが出ます。出席できないコマをタップして ×、科目ごとの希望コマ数を ＋／− で入力、授業時間（90 分・60 分・45 分）を選び、「提出する」で提出します。講習を受けない場合は「通常授業のみ」に印を付けます。
3. 提出した内容は教室側にその場で届き、「希望科目数登録済」として登録されます。提出後は本人からは変えられません。同じ QR をもう一度開くと「すでに提出済みです」と出ます。
4. やり直してもらいたいときは、室長が生徒日程表でその生徒の「登録解除」を押します。すると同じ QR で再提出できる状態に戻ります。
5. 室長が代わりに入力することもできます。生徒日程表で「希望科目数設定はここをクリック」から入力し、「登録」を押します。
6. 提出状況の一覧は、日程表の「講習集計結果」で見られます（登録／通常のみ／未登録の人数と、希望科目と授業時間）。

### 6-3. 講師の出勤予定

- 講師にも講師日程表の QR を渡します。講師は出られないコマを × にして提出します。
- 提出した講師は、講習期間の空いている机へ自動で置かれます。室長が「登録解除」を押すと、その登録で置かれた机だけが盤面から外れます（室長が手で置いた机は残ります）。

### 6-4. 講習のコマを組む

- 提出された希望の回数は「未消化講習」としてたまります。ツールバーの「未消化講習」を押すと、講習 × 生徒 × 科目ごとの残りの一覧が開きます。
- 一覧で生徒を選んで空いている席をクリックすると、講)として置かれます。希望数は変わらず、未消化の残りが 1 減ります。
- 「自動割振」でまとめて置けます（第 7 章）。
- 置いた講習をクリックして「ストックへ戻す」を押すと未消化に戻ります。「削除」はコマを消して希望数を 1 減らします（未消化には戻りません）。
- 講習のコマの科目や授業時間を変えたいときは、そのコマを「削除」して、生徒を追加し直すときに講習として選び直します。
- コマ表で手で追加した講習は、希望数には数えません。不要なら「削除」します。

### 6-5. 「後から出席可能に変更」

- 提出で × にしたコマへ室長が生徒を置こうとすると、確認が出ます。承認すると、そのコマは出席できるコマとして扱われ、日程表では黄色で表示されます。
- 講師も、講師日程表の出られないコマ（灰色）をクリックして確認すると、出られるコマに変えられます。
- 一度出席可能に変えたコマは、配置を消しても元の × には戻りません。戻すには QR からもう一度提出してもらいます。

### 6-6. 残数の見方

- 生徒日程表の講習回数表は、左が実際に置いた回数、右の括弧が希望数です。食い違いがあると画面に警告の印が出ます（印刷には出ません）。
- 希望数は提出した数、未消化は「希望数 − 置いた数 ＋ 戻した数」です。通常授業の方は「予定数」と呼び、講習の方は「希望数」と呼びます。

### 6-7. 中 3 の集団授業

- 講習期間を含む週は、盤面の 1 限の上に「集団」の行が 2 つ出ます（10:00〜11:00 と 11:10〜12:10）。
- 空いている科目のマスをクリックして集団理科か集団社会を選び、講師のマスで担当講師を選びます。
- 科目の入ったマスをクリックすると「出席者一覧」と「削除」が出ます。出席者一覧には、提出で「参加」を選んだ中 3 が全員出席の状態で並びます。欠席者だけクリックして欠席にし、「保存」で確定します。当日参加した中 3 を手で追加することもできます。
- 集団授業の出欠は、講師日程表の給与欄と生徒日程表の講習回数（集理・集社）に反映されます。集団授業に振替はありません。

## 7. 自動割振

### 7-1. できること

- 未消化の講習・振替を、条件に合う空いている席へまとめて置きます。
- 実行は「未消化講習」または「未消化振替」の一覧にある「自動割振」ボタンから行います。講習の自動割振には「未消化振替も同時に自動割り当てする」の選択があります（はじめは切になっています）。
- 置かれたコマは普通のコマと同じで、手で動かしたり消したりできます。

### 7-2. ルールの 2 区分

- 自動割振ルール画面で、ルールごとに「優先事項」か「制約事項」を選びます。
  - **優先事項**：なるべく守ります。守れなくても置き、画面に注意（赤くない）が出ます。
  - **制約事項**：必ず守ります。守れる席が無ければ置かず、未消化のまま残ります。
- 制約事項にできるのは、同日コマ数上限（1 コマ・2 コマ・3 コマ）、科目対応講師のみ、通常講師のみ、指定時限禁止の 6 つです。他のルールは優先事項だけです。
- 「既存コマは変更しない」「出席可能コマのみ」「期間内割振」の 3 つは常に守られる絶対事項で、変更できません。

### 7-3. ルールの設定

- 各ルールに「＋ 対象」で全員・学年・個人を追加し、「－ 対象」で除外を指定します。対象と除外が重なったら除外が優先です。「対象クリア」「除外クリア」で消せます。対象を設定するまでそのルールは効きません。
- ルールのグループは「上へ」「下へ」で優先順位を変えられます。順位が効くのは、講師 2 人配置・同日コマ数上限・連続／間隔・時限優先・科目分散です。科目対応講師のみ・通常講師のみ・指定時限禁止は順位を変えても効き方は変わりません。
- 「時限優先」は優先する時限の順番を 1〜5 限で並べ替えます。「指定時限禁止」は置かない時限を選びます（最低 1 つ）。
- 「ペア制約」で「この 2 人（講師か生徒）は同席させない」を登録できます。はじめは制約事項です。
- 同日コマ数上限は、通常・講習・振替を合わせたその日の本数で判定します。

### 7-4. 結果の見方

- 自動割振で置けなかった分は未消化に残ります（エラーにはなりません）。置けないときは、その机に講師がいるか、同じ時限に本人がすでにいないか、制約事項で除外されていないかを順に確認します。
- 盤面の赤い「制約事項: ○○」は手で置いたコマがルールに合わないときの注意です。優先事項の注意は赤くなりません。通常授業にはルールの注意は出ません。

## 8. 日程表・印刷・共有

### 8-1. 生徒日程表／講師日程表

1. コマ表の「生徒日程」「講師日程」を押すと、別タブで日程表が開きます。
2. 期間（開始日・終了日）と人物（名前で検索）を選び、「最新表示」を押すと反映されます。**期間を変えただけ、盤面を変えただけでは自動で変わりません。** 必ず「最新表示」を押してください。
3. 日程表に出るのは盤面に実際に置いてある授業だけです。未消化の振替は日程表には出ません（振替欄に「未定」として出ます）。
4. 回数表は、通常回数が「実績（予定数）」、講習回数が「実績（希望数）」です。食い違いがあると直下に警告の印が出ます。これは「休みで振替待ちの分がまだ置かれていない」などの正しいズレを見つけるための印で、画面にだけ出ます。
5. 講師日程表には給与計算欄があります。コマ数は出席の記録だけを数え、交通費の日数は出席記録のある日を数えます。小計は手で入力して上書きできます（空にすると自動計算に戻ります。開き直すと手入力は消えます）。
6. 校舎名・ロゴ・連絡事項（赤い注意文）は生徒用・講師用で共有されます。同じブラウザで生徒用と講師用のタブを両方開いているとき、片方を操作中はもう片方が編集できない表示になります。

### 8-2. 印刷

- 日程表の「印刷」で、表示している人の日程表を印刷します。A4 が基本です。
- 「印刷用全員表示」で全員分を続けて印刷できます。「空フォーマット印刷」で白紙の記入用ひな形を印刷できます。
- 印刷には回数表の警告の印・通常回数の予定数・提出済みの印は出ません。講習回数の括弧（予定）は印刷にも出ます。
- 盤面そのものは、コマ表の「PDF出力」で A3 縦 1 ページに出せます。押すと曜日 × 時限を選ぶ画面が出るので、出したいコマだけにチェックして「出力」します（全選択で 1 週間まるごと）。前回の選び方を覚えています。

### 8-3. 講師への共有

- コマ表の「講師日程共有」を押すと、QR コードとリンクが出ます。講師にスマホで開いてもらうと、閲覧専用の盤面（配布用盤面）が見られます。
- 配布用盤面に出るのは**保存済み**の内容です。盤面を変えたら「保存」してください。

## 9. 保存・バックアップ・復元

### 9-1. 保存

- 変更は「保存」ボタンを押すまでサーバーに入りません。ボタンが赤い「保存」のときは未保存の変更があります。押して緑の「最新データ」になったら保存済みです。
- 未保存のまま画面を閉じたりタブを閉じたりしようとすると、ブラウザの確認が出ます。確認せずに閉じると、未保存の変更は失われることがあります。
- 保存に失敗したときは、バックアップのファイルが自動でダウンロードフォルダに書き出され、画面に手順が出ます。表示に従ってください。

### 9-2. 同時に開かない

- 1 つの教室を 2 台の端末で同時に編集すると、後から保存した方で上書きされます。先に保存した側の端末には「別の端末でこの教室のデータが更新されました。画面を再読み込みしてください」と出て、保存が止まります。1 教室 1 端末で使ってください。
- 同じブラウザで同じ教室を 2 つのタブで開くと、後から開いたタブは使えません。

### 9-3. バックアップと初期設定の画面

| 項目 | 働き |
|---|---|
| 手動バックアップ | 「バックアップを書き出す」で、いま開いている教室の全データを 1 つのファイルに保存します。「バックアップを読み込む」でそのファイルから戻します（読み込む前に確認が出ます。読み込むと現在の内容は置き換わります） |
| 復元 | サーバーが 15 分ごとに取っている控えから、**直近 3 日分**の中の時点を選んで戻せます。「戻したい時点」を選び、確認画面で教室名・時点・規模（生徒数・講師数など）を確かめて読み込みます。読み込んだ段階ではまだ画面の中だけなので、「保存」を押して確定します。保存前なら「直前の状態に戻す」で取り消せます。3 日より前に戻したいときは「質問・要望」から相談してください |
| 管理データの Excel | 「テンプレート出力」で入力用の Excel、「現データ出力」で今の生徒・講師・教室データ・通常授業テンプレートを Excel に出します。「初期取り込み」は最初の一括登録、「差分取り込み」は ID 列を残したファイルで更新・追加だけを行います（ファイルに無い人は消えません） |
| 初期設定フロー | 使い始めの手順：Excel の取り込み → 机数・定休日 → 開始時点の未消化振替・講習の登録 → 「初期設定を完了してコマ表をリセットする」 |

- 復元で戻らないものがあります（QR で提出された講習の希望、保護者からの連絡、出席・休み・振替の履歴の記録）。確認画面に表示されます。
- サーバーの控えは、1 日 1 回分は長く残ります。アプリの画面から戻せるのは直近 3 日分で、それより前は開発者が対応します。

## 10. 質問・要望・不具合の送り方

1. **ボタンの場所**：コマ表のツールバー右側と、日程表タブのツールバー右側の「質問・要望」。どちらも同じ画面が出ます。
2. **3 つの種類**：「使い方の質問」「要望」「不具合」。開いたときは「使い方の質問」が選ばれています。内容は必須です。生徒名・日付・何限・どうしたら何が起きたかを書くほど確認が早くなります。
3. **送ったあと**：開発者にすぐ通知が届きます。回答は開発者が確認してから返します。回答が届くと、コマ表の「質問・要望」ボタンに未読の件数が付きます（自動で画面は開きません）。ボタンを押すと「これまでの質問と回答」に質問と回答が新しい順に並びます。「確認しました」を押すと件数が消えます（どの端末で押しても同じです）。送った質問は回答前でも「回答待ち」として残ります。
4. 日程表タブの「質問・要望」は送るだけです。履歴はコマ表側で見ます。
5. 送るときには、直近の操作の記録と画面のデータが一緒に届きます。これは原因を調べるためのもので、他の教室には見えません。

## 11. よくある質問

- **毎週同じ授業を毎週手で入れる必要はありますか？** … ありません。通常授業テンプレートに登録して保存すると、在籍している週に自動で並びます（第 3 章）。
- **今週だけ時間を変えたら来週も変わりますか？** … 変わりません。盤面で動かした変更はその週だけです。ずっと変えるときはテンプレートを直します（3-4）。
- **祝日はどう設定しますか？** … コマ表でその日付をクリックし「休日設定」を押します。その日の通常授業の生徒は未消化振替にたまります（4-4）。
- **振替の残りはどこで見られますか？** … コマ表の「未消化振替」ボタンです。数字が合計です（5-2）。
- **振替を消したのに残りが戻りません** … 「削除」は未消化に戻しません。戻すときは「ストックへ戻す」を使います（5-4）。
- **保存を押し忘れて閉じました** … 保存していない変更はサーバーに入っていません。開き直して、変更がなければもう一度操作してから「保存」します（9-1）。
- **日程表に盤面の変更が出ません** … 日程表の「最新表示」を押してください（8-1）。
- **2 台で同時に作業できますか？** … できません。後から保存した方で上書きされます（9-2）。
- **講師にスマホで予定を見せたい** … コマ表の「講師日程共有」で QR とリンクを出します（8-3）。
- **保護者に生徒の予定表を渡したい** … 「生徒日程」で生徒を選び「最新表示」→「印刷」です（8-1・8-2）。
