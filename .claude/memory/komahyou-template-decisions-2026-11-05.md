# 2026-11-05 オーナー決定(確認リスト 11/4〜11/5 の送信・壁打ちで確定)

> **2026-11-08 全教室へ昇格(v1.5.711)**: 第 2 版(段 1〜5)を v1.5.689〜v1.5.710 で開発用/テスト教室に出し、確認リスト(v2-1〜v2-6・se-1〜se-10・mg-1/mg-2)がすべて OK → オーナー指示「開発・テスト教室だけで動いている機能の 4 件を全教室展開して」で `templateDiffApply = 'all-classrooms'`。昇格前の必須だった Q33-1(旧版タブのすき間)は版が揃うまでの一時的なものとしてハードリロードで潰し、N-1(フラグを戻したときの保留の保護)は「回帰で戻さない」で封じた(会社既定で OFF にするときだけ先に実装)。残りの片づけ(§H を旧仕様として畳む・机の対応付けの一本化)は台帳 template-conflict-v2。

- **写し(同じ日の中で手で動かした通常授業)は手入力データとして残さない**。テンプレ保存でテンプレの位置に戻り、
  テンプレから外した生徒の写しも消える。11/1 の決定 53(残して緑＋「※n限にも」)は取り消し。
  残す例外は 2 つだけ: その日に出席・休みの記録がある形(H-1・INV-06)と、テンプレの席に戻せない写し(H-2・無言消失の禁止)。
- **「通常」とはテンプレ由来の授業のこと**。手動追加の振替・講習・手動追加の通常授業は手入力扱い。満席の押し出し
  (決定記録 51・59)で「同じ振替元の日の振替」でも manualAdded なら押し出す。両席ともテンプレ由来のときだけ振替が下段。
- **テンプレ机が講師だけ(生徒なし)**なら、手で置いた生徒は席(上の行)に残し、講師だけ緑(11/1 決定 52 の「上の行は空のまま」は取り消し)。
- **手置き講師 X の机があるコマで、テンプレが別の机に X を置く**ときは、手置きの机を講師の保留(上=講師なし／下=X)にして知らせる(INV-01)。
- メニューは「上段(テンプレ)を採用する／下段(手入力)を採用する／下段(手入力)を移動する／下段(手入力)を削除する」、押した席の上下をハイライト。
- 「テンプレ保存で自動並び替えが悪さ」はチャット回答: 保存は並び替えない。並び替えボタン(コマ表側で押すと机番号の突き合わせがずれる)と
  講師だけの机の詰め直しだけ。ずれた日付と時限が分かれば調べる。
- 調査の作法: 開発用教室は weekly-parts 形式(classroomSnapshots/{id} の目次 → snapshotParts/{docId} を gzip-base64 解凍)。
  15 分バックアップ workspace-auto-backups/main/15min/<JST 時刻>/<教室ID>.json.gz は { classrooms: [{ id, data }] }。

# 同日・第 2 回: 根本から作り直す(オーナー決定 2026-11-05・新仕様 docs/spec-template-conflict-v2.md)

- 今の §H(Q21〜Q42・決定記録 66 本)は場合分けが多すぎる → **置き換える**。上の 4 件の修正は作業ブランチ
  claude/fervent-maxwell-6xvhu7(コミット 3b5365b)に止めて **main へ出していない**(新仕様に吸収予定)。
- 基本規則: 反映先(机×席)に手入力データがあれば 2 行(緑)。それ以外はテンプレどおり。
- 同じ生徒が同じコマに 2 か所(手入力 vs テンプレ)→ **手入力が勝つ**(テンプレのその生徒は置かない)。前テンプレ由来なら新テンプレが採用されるだけ。
- **手入力データはすべて青字**。
- **休みが勝つ**: 生徒は休みの記録、講師は**新設の「休み」ボタン**(グレー表示・別の講師で上書き可)。休みのコマにテンプレで入っても休みが勝つ。
- **丸ごと振替は同じ曜日だけ**(運用上、別の曜日は無い)。D→D' は日付の付け替えの記録として残り、テンプレで D に新しく割り振られた授業は自動で D' へ追従する。
  D' は第 5 週など休日設定でテンプレが展開されない日のはず(移動先にテンプレが展開される日をどうするかは確認中)。
- **13 項目すべてオーナー回答済み(2026-11-05・spec §9 の決定記録)**: 講師が別の机→手入力が勝つ／D' のテンプレは消去(在庫に入れない)／予定数は D の月／講師の休みは 1 コマごと・一括なし・コマ表だけ・同じボタンで解除・削除記録は別／テンプレ由来の机は並び替えで動かさない／既存の保留と別曜日の丸ごと振替は両教室とも作り直す／青は生徒名・講師名・メモ／別の生徒の記録だけの席は置く／科目・時間の手直しは手入力／休日の振替の追従は今どおり消す／QR の講師は手入力(出自は 2 値)。
- **監査後の追加決定(§9-14〜17)**: 下段だけの手入力 S はテンプレの席へ自動で上げる／手置き X の机に W＋別の机に X なら机は X のまま(W も B の X も置かない)／休みの記録はそのコマだけ(別の時限に置くのは止めない)／別の日へ動かして戻した授業は手入力のまま。
- 段 1・2 の INV 監査(2026-11-05)で見つかった穴: 同日移動の写しを休み/削除にすると元の時限に生き返る(元の時限の権威関数を 1 つに)・編集で振替にした template 印の授業が保存で消える(区分変更で manual に)・OFF でも origin が保存に入る・下段だけの S が日程表から消える。
- **§9-18/19(統合時の確認)**: 休みの X はテンプレに居ないものとして扱う(机 A は上 W／下 X の 2 行)／休みの机に本人を置き直したら自動で休み解除。段 1〜3 統合済み(cea7e47・4383 件)。段 4(付け替え)実装中。
